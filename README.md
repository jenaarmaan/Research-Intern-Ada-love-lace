# Agentic AI - Research Internship

This repository contains the course curriculum, assignments, and research projects related to the Agentic AI curriculum for the Research Internship.

## Repository Structure

- `AgenticAI_Course_curriculum.pdf`: Course curriculum and syllabus.
- `assignment-1/`: Work related to Assignment 1: Agent Architecture Design & Analysis (located on the `assignment-1` branch).

## Curriculum Modules
1. **Module 1**: Foundations of Agentic AI
2. **Module 2**: LLM Reasoning, Planning & Tool Use
3. **Module 3**: Memory Systems & Knowledge Management
4. **Module 4**: Multi-Agent Systems & Coordination
5. **Module 5**: Evaluation, Safety & Real-World Deployment
